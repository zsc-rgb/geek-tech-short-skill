# 调用后你能得到什么？

给仓库访客 / 安装者看的「价值说明书」。Agent 也会从 `SKILL.md` 顶部的 *What callers get* 读到同类约束。

## 一句话

更快做出**能发的、专业向**竖屏技术短视频，而不是偶然撞出一条好看的。

## 七项收益

1. **频道级统一视觉** — 冷黑极客风；禁霓虹土味、全局运镜穿模、首屏死黑、硬切。
2. **三种内容形态** — 重构避坑 / 架构顿悟 / 跑分对决，避免审美疲劳。
3. **对比隐喻可装配** — IO、水箱、索引树、线程池、节点图、柱状赛道。
4. **音画可对齐** — TTS+Whisper 动态时钟；Ding/变绿跟口播走。
5. **多平台安全区** — 抖音、视频号、Shorts、B 站预设。
6. **干货底线** — 痛点钩子 + ≥1 线上避坑 + 三原则；CTA 与字幕不双胞胎。
7. **交付路径** — `job.json` v2 → 组件挂载 → CHECKLIST 出片；`PROMPT.md` 填空即用。
